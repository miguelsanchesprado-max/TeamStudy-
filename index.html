Baixe o TeamStudy

Escolha a versão para o seu dispositivo abaixo:

Mobile / Android

Aplicativo para Celular

Acesse com notificações e agilidade no seu Android.

Baixar para Celular (.APK)

Como instalar no celular:

  1. Toque no botão verde acima para baixar o TeamStudy.apk.
  2. Abra o arquivo baixado no seu celular e autorize a instalação.
Computador / PC

Aplicativo para Windows

Instale a versão Desktop no seu PC.

Baixar para Windows (.ZIP)

Como instalar no Windows:

  1. Baixe e extraia o arquivo TeamStudy-Windows.zip.
  2. Clique com o botão direito em install.ps1 e escolha Executar com o PowerShell.
