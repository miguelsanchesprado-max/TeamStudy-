Baixe o TeamStudy

Estude em grupo com melhor desempenho e notificações no seu dispositivo.

Recomendado para Celular

Versão para Android (.APK)

Instale diretamente no seu smartphone.

Baixar APK Android

Como instalar no Android:

  1. Clique no botão acima para baixar o arquivo .APK.
  2. Abra o arquivo baixado na sua barra de notificações.
  3. Se solicitado, ative a opção "Permitir desta fonte" nas configurações do seu celular.
  4. Conclua a instalação e abra o TeamStudy!
Versão Web App (PWA)

Instalar no Computador / PC

Use como aplicativo de desktop sem ocupar espaço.

Como instalar no Navegador (Chrome / Edge):

  1. No topo da barra de endereço do seu navegador, procure o ícone de Instalar (um monitor com seta para baixo).
  2. Clique no ícone e confirme em "Instalar".
  3. O TeamStudy abrirá em uma janela própria como aplicativo de desktop.
